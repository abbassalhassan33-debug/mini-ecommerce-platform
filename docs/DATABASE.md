# Database Design

## Overview

The application uses a lightweight data storage approach suitable for the scope of this assessment.

A full database system was not required because the dataset is small.

---

## Product Data

Products contain:

- id
- title
- description
- price
- stock
- variants
- image

---

## Why This Approach?

A lightweight storage solution was chosen because:

- Faster development
- Simple product structure
- No complex relationships required

---

## Future Improvements

For a larger production system, the project could migrate to:

- PostgreSQL
- MongoDB
- SQLite

The choice would depend on scalability and querying requirements.
